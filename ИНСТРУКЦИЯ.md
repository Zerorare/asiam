# 📘 Как устроен сайт АЗИЯ_М и как его менять

Руководство для того, кто хочет понимать, что происходит, а не просто нажимать кнопки.
Читается за 20 минут. Все примеры — из настоящего кода этого сайта.

---

## 1. Что такое сайт на самом деле

Сайт — это **папка с файлами**, которые лежат на компьютере, подключённом к интернету 24/7
(этот компьютер называют **сервером** или **хостингом**). Когда человек открывает
`zerorare.github.io/asiam`, его браузер скачивает эти файлы себе и рисует из них страницу.

Всё. Никакой магии. Наши файлы лежат в **репозитории** на GitHub — это папка проекта
с историей всех изменений. GitHub бесплатно раздаёт их посетителям (сервис **GitHub Pages**).

**Три типа файлов, из которых состоит любой сайт:**

| Файл | Что делает | Аналогия |
|------|-----------|----------|
| **HTML** (`.html`) | Содержимое: тексты, картинки, кнопки | Скелет и мясо |
| **CSS** (`.css`) | Внешний вид: цвета, размеры, отступы | Одежда и макияж |
| **JavaScript** (`.js`) | Поведение: реакция на клики, анимации | Мышцы и рефлексы |

На нашем сайте JavaScript совсем немного, и он живёт прямо внутри HTML-файлов (в самом низу,
между тегами `<script>`). Он делает две вещи: плавное появление блоков при прокрутке
и сборку сообщения из формы заявки.

```
asiam/
├── index.html      ← русская версия сайта (620 строк) — главная страница
├── en.html         ← английская версия
├── ko.html         ← корейская версия
├── css/
│   └── style.css   ← ВСЕ стили сразу для трёх версий (372 строки)
├── img/            ← все фотографии
│   ├── hero.jpg        (фон главного экрана)
│   ├── gallery-1..7.jpg (галерея «Наши работы»)
│   └── vladimir.jpg    (фото владельца)
├── README.md       ← описание проекта
└── ИНСТРУКЦИЯ.md   ← этот файл
```

**Важно понять:** `index.html` — особое имя. Когда открывают адрес сайта без уточнений,
сервер отдаёт именно `index.html`. Поэтому русская версия — главная, а английская
открывается по адресу `.../en.html`.

**Ещё важнее:** стили общие. Поменял цвет в `css/style.css` — изменится на всех трёх языках сразу.
А текст в `index.html` — только на русской странице.

## 3. Как читать HTML

HTML состоит из **тегов** — команд в угловых скобках. Почти все теги парные:
открывающий `<p>` и закрывающий `</p>`, между ними — содержимое.

```html
<p>Это абзац текста</p>
```

Теги вкладываются друг в друга, как матрёшки. Отступы слева показывают вложенность:

```html
<div class="card">          ← коробка (контейнер)
  <h3>Выездной фуршет</h3>  ← заголовок внутри коробки
  <p>Описание услуги</p>    ← абзац внутри той же коробки
</div>                      ← коробка закрылась
```

**Основные теги, которые есть на нашем сайте:**

| Тег | Что это |
|-----|---------|
| `<div>` | Универсальная коробка, контейнер для чего угодно |
| `<section>` | Смысловой раздел страницы (услуги, меню, контакты) |
| `<h1>`…`<h3>` | Заголовки: `h1` — самый крупный, один на страницу |
| `<p>` | Абзац текста |
| `<a href="...">` | Ссылка. `href` — куда ведёт |
| `<img src="..." alt="...">` | Картинка. `src` — путь к файлу, `alt` — описание для незрячих и поисковиков |
| `<ul>` / `<li>` | Список / пункт списка |
| `<b>`, `<em>` | Жирный / выделенный текст |
| `<br>` | Перенос строки (одиночный тег, закрывать не надо) |

**Атрибуты** — это дополнения внутри открывающего тега: `class`, `href`, `src`, `id`.
Самый важный для нас — **`class`**. Это «ярлык», по которому CSS понимает, как красить элемент.

## 4. Как читать CSS

CSS — это список правил вида «кому» → «что сделать»:

```css
.dish {                          ← кому: всем элементам с class="dish"
  background: #ffffff;           ← что: белый фон
  border-radius: 12px;           ←      скруглить углы на 12 пикселей
  padding: 12px 14px;            ←      внутренние отступы
}
```

Каждая строка внутри фигурных скобок — **свойство: значение;** (точка с запятой обязательна).

**Как CSS находит элемент:**

| Запись в CSS | Что означает |
|---|---|
| `.card` | все элементы с `class="card"` |
| `#buffet` | элемент с `id="buffet"` (id уникален, только один на странице) |
| `h2` | все заголовки `<h2>` |
| `.pack .top` | элементы с классом `top` **внутри** элементов с классом `pack` |
| `.card:hover` | карточка **в момент наведения** мыши |

**Фирменные цвета вынесены в переменные** — в самом начале `css/style.css`:

```css
:root{
  --wine:#6e1b21;    ← бордовый (шапка, заголовки пакетов)
  --gold:#dcb877;    ← золотой (цены, акценты)
  --paper:#faf5ee;   ← фон страницы
}
```

Дальше по файлу они используются так: `color: var(--wine)`.
**Это значит: поменяешь `--wine` в одном месте — перекрасится весь сайт разом.** Очень удобно.

## 5. Как HTML и CSS связаны — на живом примере

Открой `index.html`, строка ~68. Там блок с фактом на главном экране:

```html
<div class="fact"><b>от 50 000 ₩</b><small>фуршет / человек</small></div>
```

Теперь открой `css/style.css` и найди `.fact`:

```css
.fact{
  background:rgba(255,255,255,.07);
  border:1px solid rgba(255,255,255,.12);
  border-radius:14px;
  padding:14px 20px;
}
.fact b{display:block;font-size:1.25rem;color:var(--gold)}
```

Связь: в HTML написано `class="fact"` → в CSS правило `.fact` → браузер применяет к нему эти стили.
А `.fact b` означает «жирный текст **внутри** блока с классом fact» — то есть цена
становится золотой и крупной. Вот и весь механизм.

## 7. Пять типовых задач — пошагово

### 7.1 Поменять цену

Пример: фуршет «Стандарт» подорожал с 60 000 до 65 000 ₩.

1. Ищем в `index.html` текст `60 000 ₩`
2. Находим строку в разделе фуршета:
   ```html
   <div class="p-price">60 000 ₩ <small>/ персона</small></div>
   ```
3. Меняем число. **Только число, теги не трогаем!**
4. Проверяем, не упомянута ли цена ещё где-то (в кнопке заказа, в фактах на главном экране)
5. Повторяем то же самое в `en.html` (там `₩60,000`) и `ko.html` (там `60,000원`)

### 7.2 Поменять текст

Находим нужную фразу поиском и переписываем **между** тегами:

```html
<h3>Выездной фуршет</h3>          ← было
<h3>Фуршет под ключ</h3>          ← стало
```

Не трогаем сами `<h3>` и `</h3>` — иначе вёрстка сломается.

### 7.3 Добавить блюдо в меню

Находим похожее блюдо и копируем его блок целиком:

```html
<div class="dish"><div class="d-info"><div class="d-name">Чапче</div></div><a class="d-wa" target="_blank" rel="noopener" href="https://wa.me/821080247552?text=...">Заказать</a></div>
```

Вставляем копию рядом и меняем название в `d-name`. В ссылке текст после `?text=`
закодирован (русские буквы превращаются в `%D0%97...`) — проще всего попросить меня
пересобрать меню, чем кодировать вручную.

### 7.4 Заменить фотографию

1. Кладём новый файл в папку `img/` (например, `gallery-8.jpg`)
2. **Обязательно сжимаем перед загрузкой!** Фото с телефона весит 10 МБ — сайт будет
   грузиться вечность. Нужна ширина ~1200 пикселей и вес до 300 КБ
3. В HTML добавляем/меняем:
   ```html
   <figure><img src="img/gallery-8.jpg" alt="Описание фото" loading="lazy"></figure>
   ```

### 7.5 Поменять цвет сайта

Открываем `css/style.css`, первые строки, меняем значение переменной:

```css
--wine:#6e1b21;   →   --wine:#1b4d3e;   (например, на изумрудный)
```

Цвета задаются в формате `#RRGGBB` (шестнадцатеричный код). Подобрать удобно
на любом сайте-палитре, например `coolors.co`.

## 8. ⚠️ Правило трёх языков

У нас **три HTML-файла**. Если правишь текст или цену — правь **во всех трёх**,
иначе клиенты увидят разные цены на разных языках. Это самая частая ошибка.

- Правка **текста/цены** → `index.html` + `en.html` + `ko.html`
- Правка **стилей/цветов** → только `css/style.css` (применится сразу ко всем)
- Правка **фото** → файл в `img/` меняется один раз, но путь может быть прописан во всех трёх

## 9. Как редактировать: два способа

### Способ А — прямо в браузере на GitHub (проще, для мелких правок)

1. Открываешь https://github.com/Zerorare/asiam
2. Кликаешь на нужный файл, например `index.html`
3. Жмёшь **карандаш ✏️** справа сверху (Edit this file)
4. Правишь текст. Поиск по файлу — Ctrl+F / Cmd+F
5. Внизу кнопка **Commit changes** → пишешь коротко, что изменил («поднял цену фуршета»)
6. Через 1–2 минуты сайт обновится сам

**Плюс:** ничего не надо устанавливать, работает даже с телефона.
**Минус:** не видно результат до публикации.

### Способ Б — на компьютере (правильный, для серьёзной работы)

Понадобится:
- **VS Code** — бесплатный редактор кода (code.visualstudio.com)
- **Git** — программа, которая синхронизирует твою папку с GitHub (git-scm.com)

Порядок работы:

```bash
# 1. Один раз: скачать проект себе
git clone https://github.com/Zerorare/asiam.git
cd asiam

# 2. Каждый раз перед работой: забрать свежую версию
git pull

# 3. ... правишь файлы в VS Code, смотришь результат ...

# 4. Отправить изменения на сайт
git add .                              # взять все изменённые файлы
git commit -m "поднял цену фуршета"    # подписать, что сделал
git push                               # отправить на GitHub
```

**Как посмотреть результат до публикации:** просто открой `index.html` двойным кликом —
он откроется в браузере с диска. Ещё удобнее — расширение **Live Server** в VS Code:
страница сама обновляется при каждом сохранении.

## 10. Если что-то сломалось

**Главное: в Git ничего не теряется.** Любую версию можно вернуть.

- На GitHub открой файл → кнопка **History** → выбери версию до поломки → **Revert**
- Или найди свой коммит в списке коммитов и нажми «Revert» — GitHub сам откатит изменения

**Частые ошибки новичка:**

| Симптом | Причина |
|---------|---------|
| Кусок страницы уехал или пропал | Забыл закрывающий тег (`</div>`) или удалил лишний |
| Стиль не применился | Опечатка в имени класса, или забыл `;` в CSS, или не закрыл `}` |
| Картинка не отображается | Неверный путь. Из HTML пишем `img/foto.jpg`, а из CSS — `../img/foto.jpg` (потому что CSS лежит в подпапке) |
| Изменения не видно на сайте | Прошло меньше 2 минут, либо кэш браузера — обнови Ctrl+Shift+R |
| Всё поехало после вставки текста из Word | Word подставляет «умные» кавычки и невидимые символы. Вставляй через «Вставить как простой текст» |

## 11. Словарь терминов

- **Репозиторий (repo)** — папка проекта на GitHub со всей историей изменений
- **Коммит (commit)** — сохранённое изменение с подписью. Как «сохранение» в игре
- **Ветка (branch)** — параллельная версия проекта. `main` — основная, та, что показывается людям
- **Pull request (PR)** — предложение влить изменения из ветки в `main`
- **Merge** — влить изменения в основную ветку
- **Push / pull** — отправить свои изменения на GitHub / забрать чужие себе
- **Деплой (deploy)** — публикация сайта. У нас происходит автоматически после merge в `main`
- **Хостинг** — компьютер, где лежит сайт. У нас — GitHub Pages, бесплатно
- **Домен** — красивый адрес сайта (`asiam.kr`). Покупается отдельно, ~₩20 000/год
- **DNS** — «телефонная книга» интернета: связывает домен с адресом сервера
- **Тег** — команда HTML в угловых скобках
- **Класс** — ярлык на элементе, по которому CSS его находит
- **Адаптивность** — способность сайта нормально выглядеть и на телефоне, и на компьютере

## 12. Что учить дальше

Порядок именно такой, не перепрыгивай:

1. **HTML** — теги, вложенность, атрибуты. Хватит 3–5 дней
2. **CSS** — селекторы, box model (отступы/границы), flexbox и grid для раскладки. 2–3 недели
3. **Адаптивность** — медиазапросы `@media`, чтобы сайт подстраивался под экран телефона
4. **Git** — commit, push, pull, ветки. Достаточно базы
5. **JavaScript** — только когда первые четыре пункта уложились в голове

**Где учиться бесплатно:**
- [MDN Web Docs](https://developer.mozilla.org/ru/) — официальная документация, лучший справочник
- [freeCodeCamp](https://www.freecodecamp.org/) — практический курс с задачами
- [htmlacademy.ru](https://htmlacademy.ru/) — бесплатные интерактивные курсы на русском
- [CSS-Tricks](https://css-tricks.com/) — разборы приёмов вёрстки

**Главный совет:** не читай книги подряд. Открой этот сайт, поставь себе задачу
(«поменять цвет кнопки», «добавить блюдо») и делай её. Сломал — откатил и попробовал снова.
За неделю такой практики поймёшь больше, чем за месяц теории.
